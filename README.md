# Myslot for 3.3.5

A backport of [Myslot](https://github.com/tg123/myslot) by Boshi Lian (tg123) for World of Warcraft 3.3.5a (WotLK).

Myslot saves and transfers your action bars, macros and key bindings between characters and accounts, using export strings you can copy and paste. Saved profiles are kept in the addon so you can switch between setups.

## Installation

1. Download this repository (**Code → Download ZIP**) and extract it.
2. Copy the `Myslot` folder into `World of Warcraft\Interface\AddOns\`.
   The folder must be named exactly `Myslot`.
3. Remove any older version of MySlot first.

## Usage

Type `/myslot` or click the minimap icon.

- **Export** puts your current setup in the text box. **Save** stores it as a profile.
- To apply a profile, pick it from the profile list (or paste a string) and click **Import**.
- The arrows next to Export and Import choose what to include or skip.
- Before each import your current setup is backed up as **Before Last Import**.
